## 🛠️ Local Editing & Testing Instructions

You can edit and test this entire website on your computer with **zero build tools required**.

### Option 1: Quick Double-Click (Easiest)
1. Open the project folder `arc-editz-portfolio`.
2. Double-click on `index.html` to open it in Chrome, Edge, or Firefox.

### Option 2: Live Local Web Server (Recommended for Live Reload)
If you use **VS Code**:
1. Open VS Code and click `File > Open Folder...` -> Select `arc-editz-portfolio`.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and select **"Open with Live Server"**.

Alternatively, via Command Prompt / PowerShell:
```sh
npx -y serve .
```
Open `http://localhost:3000` in your browser.

## 🌐 How to Upload & Host For FREE on Netlify

Netlify gives you a free `.netlify.app` web link and custom domain support with 100% free hosting.

### Method A: Netlify Drag-and-Drop (Fastest — 1 Minute)
1. Go to [https://app.netlify.app/drop](https://app.netlify.app/drop) (or log in to [netlify.com](https://www.netlify.com/)).
2. Drag and drop the whole `arc-editz-portfolio` folder directly into the browser upload box.
3. Done! Netlify will give you a free live URL (e.g. `arc-editz.netlify.app`).

### Method B: Netlify CLI
1. Open terminal inside the project directory:
   ```sh
   npx netlify-cli deploy --prod
   ```
2. Follow the prompt to log in and select "Create & deploy new site".

## ⚡ How to Upload & Host For FREE on Vercel

Vercel provides ultra-fast global CDN hosting for free with a `.vercel.app` URL.

### Method A: Vercel CLI (1 Minute)
1. Open terminal inside `arc-editz-portfolio` folder.
2. Run:
   ```sh
   npx vercel
   ```
3. Press `Enter` to accept defaults. Vercel will build and output your live deployment link!

### Method B: GitHub + Vercel Dashboard
1. Push your `arc-editz-portfolio` project to a new repository on GitHub.
2. Go to [vercel.com](https://vercel.com/) and click **"Add New Project"**.
3. Select your GitHub repository and click **"Deploy"**.
4. Every time you push edits to GitHub, Vercel will automatically update your live site for free!
